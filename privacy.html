プライバシーポリシー

最終更新日：2026年10月3日

対象

本ポリシーは、個人用ツール「Claude Sheets」（以下「本ツール」）に適用されます。本ツールの利用者は開発者本人のみです。

取得する情報

本ツールは、Google の OAuth 認証により、利用者本人の Google スプレッドシートおよび Google ドライブへのアクセス権を取得します。

利用目的

取得したアクセス権は、利用者本人の指示に基づき、スプレッドシートの閲覧・作成・編集を行うためだけに使用します。

保存と第三者提供

  • 認証情報（トークン）は利用者本人の PC 内にのみ保存され、開発者が運営するサーバーへ送信・保存することはありません。
  • 取得したデータを販売したり、広告目的で利用したり、第三者に提供したりすることはありません。
  • スプレッドシートの内容は、利用者本人の指示に応じて、本人が利用する AI アシスタント（Claude）に渡されることがあります。

Google API サービスのユーザーデータポリシーへの準拠

本ツールによる Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use 要件を含む）に準拠します。

アクセス権の取り消し

利用者は Google アカウントの「サードパーティ製のアプリとサービス」からいつでもアクセス権を取り消せます。
